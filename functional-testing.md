# Functional Testing 🧪

## What is Functional Testing?

Functional testing verifies that a software application's features work according to the specified requirements.

It focuses on **what the system does**.

## Examples

For an e-commerce application, functional testing can verify:

- User registration
- Login and logout
- Product search
- Product selection
- Add to cart
- Remove from cart
- Checkout
- Payment
- Order confirmation

## Functional Testing Process

1. Understand the requirements
2. Identify the functionality to test
3. Create test scenarios
4. Create test cases
5. Prepare test data
6. Execute test cases
7. Compare actual and expected results
8. Report defects
9. Retest fixed defects
10. Perform regression testing

## Example

### Requirement

A user should be able to add an available product to the shopping cart.

### Test Case

**Test Case ID:** TC-FUNC-001

**Steps:**

1. Open the application.
2. Search for an available product.
3. Open the product.
4. Click **Add to Cart**.
5. Open the shopping cart.

**Expected Result:**

The selected product should be displayed in the shopping cart with the correct price and quantity.

## Types of Functional Testing

- Unit Testing
- Integration Testing
- System Testing
- Smoke Testing
- Sanity Testing
- Regression Testing
- User Acceptance Testing

## Functional vs Non-Functional Testing

| Functional Testing | Non-Functional Testing |
|---|---|
| Tests what the system does | Tests how well the system works |
| Focuses on functionality | Focuses on performance, usability, security, etc. |
| Example: Login works correctly | Example: Login responds within 2 seconds |

## Key Point

**Functional testing verifies whether the software performs its required functions correctly.**
