# Manual Testing 🧪

## What is Software Testing?

Software testing is the process of checking a software application to identify defects and verify that it works according to the specified requirements.

## What is Manual Testing?

Manual testing is a software testing process where testers execute test cases manually without using automation tools.

## Why is Software Testing Important?

Software testing helps to:

- Find defects before software is released
- Verify that requirements are satisfied
- Improve software quality
- Improve user experience
- Reduce the risk of failures

## Software Testing Life Cycle (STLC)

The main phases of STLC are:

1. Requirement Analysis
2. Test Planning
3. Test Case Design
4. Test Environment Setup
5. Test Execution
6. Defect Reporting
7. Test Closure

## Types of Testing

### Functional Testing

Checks whether the software functions according to the requirements.

### Regression Testing

Checks whether existing functionality still works after changes are made.

### Smoke Testing

A basic test to verify that the important functions of an application are working.

### Sanity Testing

A focused test performed after minor changes or fixes to verify that the specific functionality works correctly.
